# notion_publish_article
使用notion直接发布文章到公众号，支持图文和图片

# 使用

1. config-example.py 改为 config.py 
2. 修改config.py里面的参数 
3. 运行main.py

## 📝 文章管理模板使用说明

功能：一站式管理公众号内容，支持直接发布到微信平台

运行要求：需配合后台自动化程序使用

### 字段说明

| **字段** | **作用说明** | **必填** | **示例值** |
| --- | --- | --- | --- |
| **标题** | 公众号文章正式标题 | ✓ | 《AI写作指南》 |
| **封面图片** | 图文消息的封面图（小绿书类型无需） | ✗ | **`image.jpg`** |
| **状态** | 自动化流程控制：• **`待发布`** → 后台自动抓取• **`已发布`** → 同步完成标识 | ✓ | 待发布/已发布 |
| **阅读原文** | 文章底部跳转链接（可选） | ✗ | **`https://example.com`** |
| **文章类型** | 发布形式：• **`图片`**：小绿书卡片• **`图文`**：常规公众号文章 | ✓ | 图文 |
| **发布时间** | 后台自动回填：文章成功发布后更新 | ✗ | 2025-07-23 20:00 |
